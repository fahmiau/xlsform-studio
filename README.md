# xlsform-studio

Offline-first desktop IDE for authoring [XLSForm](https://xlsform.org/) `.xlsx`
files, built with Tauri v2, React 19, and TypeScript.

> Status: **Stage 1 — Foundation** (typed core model, `.xlsx` read/write,
> undo-capable store, file workflow, CI gates). The grid editor lands in
> Stage 2. See [plan.md](./plan.md) and [plans/](./plans).

## Requirements

- Node 22 LTS (`pnpm` 12)
- Rust stable (`rust-toolchain.toml`)
- Windows: WebView2 Evergreen (preinstalled on Windows 11)
- Linux: `libwebkit2gtk-4.1-dev`, `libappindicator3-dev`, `librsvg2-dev`,
  `patchelf`, `libgtk-3-dev`
- macOS: Xcode command line tools

## Commands

| Command                                      | Purpose                                                |
| -------------------------------------------- | ------------------------------------------------------ |
| `pnpm install`                               | Install frontend dependencies                          |
| `pnpm dev`                                   | Vite dev server (browser preview; no native IPC)       |
| `pnpm tauri dev`                             | Native app                                             |
| `pnpm build`                                 | Typecheck and build the web assets                     |
| `pnpm lint` / `pnpm typecheck` / `pnpm test` | Quality gates                                          |
| `pnpm coverage`                              | Unit tests with the `src/core` ≥ 90% line gate         |
| `pnpm format:check`                          | Prettier                                               |
| `pnpm bench:xlsx` / `pnpm bench:indexes`     | Reference-form benchmarks                              |
| `pnpm fixtures`                              | Regenerate the synthetic corpus and the reference form |
| `pnpm bindings` / `pnpm bindings:check`      | Regenerate / verify Specta bindings                    |
| `pnpm test:e2e`                              | Playwright smoke tests with mocked IPC                 |

Rust: `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo test` (all with
`--manifest-path src-tauri/Cargo.toml`).

## Layout

```
src/core/        pure TypeScript: model, xlsx I/O, indexes, ops (no React/Tauri)
src/state/       zustand stores: document (zundo), derived indexes, UI
src/features/    shell + file workflow
src/ipc/         bindings.ts — generated by tauri-specta, do not edit
src-tauri/       Rust shell, commands, Specta registration
tests/fixtures/  .xlsx corpus + reference-form generator
docs/adr/        architecture decision records
```

`src/core` may not import React, Zustand, Tauri, or app-layer modules; ESLint
enforces this (`no-restricted-imports`).

## Optional native diagnostics (Windows x64)

```powershell
$env:TAURI_AGENT_KIT = "1"
pnpm tauri dev --features agent-kit
```

Debug builds only; release builds never start the bridge. See ADR 0003.

## Distribution

v1 installers are **unsigned** (Q3). Windows SmartScreen and macOS Gatekeeper
will warn on first launch; use "More info → Run anyway" / right-click → Open.
